# @firefly0621/dsh-client-ui-remote-control

[English](README.md) | 中文

Web 设置中 **远程控制** 页面：**配对** 标签页的中继地址输入框旁 **连接** 按钮会先保存地址再拨出连接（已连接时切换为 **断开连接**），配对成功后展示配对二维码 + 6 位配对码 + 有效期（配对上后可 **刷新** 重读状态）；**设备** 标签页负责已绑定设备的删除与"重置设备身份"。浏览器插件注册一个 id 为 `remote` 的本地化 `settings.section` 贡献；首次打开该页面才挂载组件，通过 `api-remotes` 懒调用 `ctx.remote.remoteControl.*`。

## 模型体验

无：纯展示 host 配对状态，不注册 prompt、tool 或 provider 请求。

## 已知限制与暂缓事项

- **配对码由中继铸造** —— 页面只展示连接过程中中继下发的配对码，无法自行轮换（重连可强制换新码）。
- **依赖 host 插件与可达中继** —— 未挂载 `@firefly0621/dsh-remote-control` 或中继不可达时页面显示错误状态；设备管理需要活动连接。
- **导航图标为设置外壳的齿轮兜底** —— 设置导航图标映射归属核心包 `ui-settings-general`；自定义图标需上游契约变更。
